# Project Name:
 Alzikrayat
# A simple Description:
Alzikrayat is a dynamic web application built entirely from 
scratch using pure PHP and MVC architecture. It provides a 
secure and interactive platform where users can register, 
log in, upload personal memories and photos, explore 
galleries, and interact through comments and profile 
management without relying on any external frameworks.
# Technologies:
PHP | MySQL | HTML5 | CSS3 | JavaScript | Bootstrap CSS | MVC Pattern & 3-Tier Architecture with Custom Regex Manual Router
#  How to run:
1. download the project repository into your local server 
directory
2. Start Apache and MySQL services from your XAMPP
3. Open phpMyAdmin in your browser 
(http://localhost/phpmyadmin/) and create a new 
database named alzikrayat
4. Import the provided database SQL file into your newly 
created database.
5.Configure your database connection credentials in the 
config/database.php 
6. Open your web browser and navigate to 
http://localhost/alzikrayat/public/
